# Project Summary

OdontoAgenda é um sistema interno de demonstração para clínicas odontológicas. Ele permite que funcionários organizem compromissos de clientes, definam serviços e horários de atendimento, acompanhem a agenda diária ou semanal e evitem conflitos de horário. A aplicação não possui login, pagamentos online ou backend nesta versão; os dados são persistidos no navegador.

# Project Module Description

- **Agenda:** visualização diária e semanal com navegação entre períodos, horários disponíveis, eventos coloridos por serviço e indicação do horário atual.
- **Agendamentos:** cadastro de cliente, contato, serviço, data, horário, status e observações.
- **Edição e cancelamento:** atualização de compromissos, cancelamento com visualização esmaecida e exclusão definitiva de cancelados.
- **Serviços:** cadastro, edição e exclusão de procedimentos, duração, descrição e cor da agenda. Inclui serviços odontológicos de exemplo.
- **Disponibilidade:** configuração dos dias e horários semanais de atendimento, incluindo fechamento de dias e cópia dos horários de segunda-feira.
- **Validação de conflitos:** seleção apenas de horários livres e bloqueio de sobreposição entre agendamentos ativos.
- **Persistência local:** dados armazenados automaticamente no `localStorage` do navegador.
- **Responsividade:** navegação lateral para desktop e menu em painel para dispositivos menores.

# File Description Inventory

| Arquivo ou grupo | Descrição |
|---|---|
| `src/pages/Index.tsx` | Integra a navegação, agenda, indicadores de status e diálogos. |
| `src/lib/store.ts` | Define serviços, agendamentos, horários semanais, persistência local, slots e conflitos. |
| `src/components/AgendaView.tsx` | Renderiza a agenda em modo dia ou semana e abre agendamentos por clique. |
| `src/components/AppointmentDialog.tsx` | Valida e salva novos agendamentos ou alterações. |
| `src/components/ServicesPanel.tsx` | Gerencia procedimentos odontológicos e suas propriedades visuais. |
| `src/components/AvailabilityPanel.tsx` | Permite configurar os horários de atendimento por dia da semana. |
| `src/index.css` | Aplica o tema teal clínico, variáveis de cor, tipografia e estilos globais. |
| `src/components/ui/*` | Biblioteca de componentes acessíveis para botões, diálogos, campos, seletores, menus e demais elementos de interface. |
| `src/hooks/*` | Hooks auxiliares para responsividade e notificações. |
| `src/lib/api.ts`, `config.ts`, `utils.ts` | Pontos de extensão e funções utilitárias da aplicação. |
| `src/blog-routes.tsx`, `src/pages/blog/*`, `src/components/blog/*`, `src/lib/blog.ts` | Estrutura complementar para conteúdo de blog e prerenderização. |
| `prerender/*` | Scripts de geração de páginas, rotas e sitemap do blog. |
| Arquivos de configuração da raiz | Definem build, lint, TypeScript, Tailwind, PostCSS e parâmetros do template. |

# Usage

```bash
cd app/frontend
pnpm install
pnpm run lint
pnpm run build
pnpm run dev
```

A aplicação é iniciada sem autenticação. Na primeira execução, o sistema cria serviços, horários e agendamentos de demonstração. Alterações posteriores ficam salvas no armazenamento local do navegador.
