# Project Summary

OdontoAgenda é um sistema interno para clínicas odontológicas que organiza pacientes, serviços, horários e consultas em uma agenda visual. A equipe pode acompanhar a rotina por dia, semana ou mês, cadastrar e editar agendamentos, configurar a disponibilidade de atendimento e evitar conflitos entre consultas. Os dados são persistidos localmente no navegador, sem autenticação, pagamentos ou backend.

# Project Module Description

- **Agenda:** visualização diária, semanal e mensal, com navegação entre períodos e botão “Hoje”.
- **Visão mensal:** grade completa de segunda a domingo, dias fora do mês esmaecidos, agendamentos em chips coloridos, indicador de consultas adicionais e criação rápida por dia.
- **Interação mensal:** clique em um dia abre sua agenda diária; clique em um agendamento permite edição; o botão “+” cria um novo registro.
- **Agendamentos:** cadastro de paciente, contato, serviço, data, horário, status e observações.
- **Edição e cancelamento:** alteração de consultas, cancelamento visualmente esmaecido e exclusão definitiva de registros cancelados.
- **Serviços:** cadastro, edição e exclusão de procedimentos, com duração, descrição e cor.
- **Disponibilidade:** configuração dos dias e horários semanais, fechamento de dias e cópia dos horários de segunda-feira.
- **Validação de conflitos:** exibição de horários disponíveis e bloqueio de sobreposição entre consultas ativas.
- **Persistência local:** armazenamento automático em `localStorage`.
- **Responsividade:** navegação lateral em telas grandes e menu em painel em dispositivos menores.
- **Blog e prerenderização:** estrutura complementar para páginas, rotas e sitemap de blog.

# File Description Inventory

| `src/hooks/*` | Contém hooks de responsividade e notificações. |

# Usage

```bash
cd app/frontend
pnpm install
pnpm run lint
pnpm run build
pnpm run dev
```

A aplicação inicia sem autenticação e cria dados de demonstração na primeira execução. As alterações são mantidas no armazenamento local do navegador.
