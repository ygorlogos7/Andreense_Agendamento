# Project Summary

OdontoAgenda é um sistema interno para clínicas odontológicas, criado para organizar a rotina de atendimento. A equipe pode cadastrar pacientes, serviços e horários, acompanhar a agenda diária ou semanal e evitar conflitos entre consultas. A aplicação funciona sem autenticação, pagamentos ou backend, mantendo os dados no navegador. O projeto também foi publicado no repositório remoto do GitHub, na branch `main`.

# Project Module Description

- **Agenda:** visualização diária e semanal, navegação entre períodos, indicação do horário atual e eventos coloridos por serviço.
- **Agendamentos:** cadastro de paciente, contato, serviço, data, horário, status e observações.
- **Edição e cancelamento:** alteração de consultas, cancelamento com visual esmaecido e exclusão definitiva de registros cancelados.
- **Serviços:** cadastro, edição e exclusão de procedimentos, com duração, descrição e cor.
- **Disponibilidade:** configuração dos dias e horários semanais de atendimento, incluindo fechamento de dias e cópia dos horários de segunda-feira.
- **Validação de conflitos:** exibição apenas de horários disponíveis e bloqueio de sobreposição entre consultas ativas.
- **Persistência local:** armazenamento automático dos dados no `localStorage`.
- **Responsividade:** navegação lateral em telas grandes e menu em painel em dispositivos menores.
- **Publicação:** código-fonte versionado no GitHub, com branch principal `main`.

# Usage

```bash
cd app/frontend
pnpm install
pnpm run lint
pnpm run build
pnpm run dev
```

A aplicação inicia sem autenticação e cria dados de demonstração na primeira execução. Alterações posteriores são mantidas no armazenamento local do navegador. Para obter o código, clone o repositório GitHub e execute os comandos acima dentro de `app/frontend`.
